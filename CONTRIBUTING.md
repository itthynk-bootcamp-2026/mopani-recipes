# Contributing a recipe

You don't need write access. Use the fork-and-pull-request flow:

1. **Fork** this repository to your account.
2. **Clone** your fork and create a branch, for example `add-chakalaka`.
3. Copy `recipes/TEMPLATE.md` to `recipes/<your-name>-<dish>.md` and fill it in.
4. Commit, push to **your fork**, and open a pull request to **this** repository.
5. A maintainer reviews it. Please be patient and kind (see the code of conduct).
